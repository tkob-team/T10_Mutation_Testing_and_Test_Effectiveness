# T10 Mutation Testing & Test Effectiveness

Repo tài liệu seminar Nhóm 12, Software Testing, FIT@HCMUS. Nhóm dùng **StrykerJS + Claude** trên EShop backend để đánh giá assertions và chuẩn bị guide, report, demo, activity.

## Start Here

1. Đọc [Project Context](CONTEXT.md); khi dùng agent, bắt đầu với [AGENTS.md](AGENTS.md).
2. Đọc [Requirements](docs/requirements/Seminar_Requirements_Consolidated.md) cho task được giao.
3. Tra [Working Guide](docs/Working_Guide.md) và [Task Output Map](docs/Task_Output_Map.md), tạo file từ template khi bắt đầu.
4. Bàn giao artifact/evidence để review; dùng checklist stage và Submission trước khi nộp.

Preparation–S2 do Thái Hòa phụ trách. Từ S3, cả ba chia công việc theo domain/section. [Working Files](CONTEXT.md#working-files) dẫn tracker/flow; teammate chỉ clone repo vẫn có context, requirements và templates để bắt đầu.

## Contributing

Ghi Task ID vào commit/PR. Written contributions từ S3 bàn giao riêng; người được giao assembly hợp nhất. AI usage dùng [Individual AI Record](ai-audit/AI_Record_TEMPLATE.md); mỗi người tự review, viết reflection và ký bản nộp của mình. Chỉ đánh dấu Done sau khi output đạt yêu cầu và có evidence review.
